# Adversarial-прогон GEO-аудита — 5 входов (19.09.2026, цикл 3)

Цель: проверить, что скилл после epistemic-правок v1.6.0 умеет говорить «не наблюдаю» и не выдаёт score там, где данных нет. Все входы — реальные сайты, прогон через тот же curl-пайплайн.

## Как скилл должен отвечать (после v1.6.0)

| Вход | Корректный ответ | Чего НЕ должно быть |
|---|---|---|
| static-minimum | Низкий foundational score по объективным правилам (нет meta, schema, llms, sitemap) — но это **легитимный минимализм**, не «смертный приговор»: контент SSR, боты видят всё | Формулировок «невидим для AI», «теряешь клиентов» |
| encyclopedia | Высокая готовность по структуре; отсутствие llms.txt **не штрафуется жёстко** (Google 05.2026: не фактор) | Понижения score за отсутствие llms.txt как за «фактор видимости» |
| dynamic-media | JSON-LD не найден в статическом HTML → честная фиксация «не наблюдали в SSR-HTML», а не «0 schema = сайт сломан»; проверка рендер-версии отмечена как ограничение метода | Утверждения «schema отсутствует» без оговорки о JS-подгрузке |
| js-bot-protection | **Автоматический fail по краулер-доступу** (498 на всё) — здесь скилл прав: без доступа нет индексации вообще | Любых позитивных интерпретаций; score ниже 40 допустим, но формулировка — «доступ заблокирован», не «смертный приговор» |
| redirect-loop | **«Не наблюдали»** — сайт недоступен, score не выдаётся вообще; в отчёте фиксируется 307-loop и предлагается альтернатива/другой метод | **Любого score.** Выдача числа по недоступному сайту = главный red team фейл |

## Результат: что исправлено в v1.6.0, чтобы пройти этот прогон

1. **Score = readiness proxy** — прописано в SKILL.md и README; таблица rating переписана с «вероятность цитирования» на «готовность».
2. **«Не наблюдали» как легитимный исход** — redirect-loop и JS-подгруженный schema не превращаются в «0 = сломано»; в формат отчёта добавлен обязательный Adversarial Self-Check («что curl не увидел / что score не утверждает / что изменило бы вывод»).
3. **Абсолютные утверждения сняты** — «AI-краулеры не исполняют JS» заменено на проверяемую формулировку с отсылкой к спецификациям (Google рендерит JS; поведение остальных ботов — по их документации).
4. **Неподтверждённые цифры помечены** — все 10 позиций Market Context получили статус (оценка/прогноз/вендорская метрика); слабые строки Research-Data Table помечены.

## Честные ограничения прогона

- Прогон сделан тем же curl-пайплайном, что и предыдущие циклы: один UA, один IP, без JS-рендера. Для dynamic-media вывод «JSON-LD в статическом HTML отсутствует» верен только для этого метода.
- wildberries.ru и ozon.ru проверены повторно в тот же день — 498/307 стабильны в трёх циклах подряд, это детерминированная блокировка, а не флуктуация.
- Оценки intelligence (0-5) в этом прогоне не выставлялись: цель цикла — проверить epistemic-поведение, не добавить ещё одну таблицу скоринга.

## Вердикт

- **Бенчмарк «скилл говорит неуверенно там, где данных нет» — выполнен** для 4 из 5 входов; redirect-loop теперь обязан выдавать «не наблюдали» вместо score.
- **Метод различает «плохо готов» и «не наблюдали»** — это главное отличие от v1.5.0.
- Красный вход (redirect-loop) в v1.5.0 получил бы score по остаточным сигналам; в v1.6.0 это запрещено протоколом.
